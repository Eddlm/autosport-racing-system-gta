# AUDIT 211 — documentation against code

**Surface**: every claim in the doc set that a reader would use to make a decision — a law with a value, a mechanism, a call order, a shipped default or a state tag. Scope: `AGENTS.md`, `AGENTS/AGENTS-STEERING.md`, `AGENTS/AGENTS-TECHNOTES.md`, `AGENTS/AGENTS-WIP.md`, `AGENTS/AGENTS-BACKLOG.md`, `AGENTS/AGENTS-VEHICLE-STATUS.md`, `TEST-PLAN.md`, `docs/release-0.9.0.md`, `docs/OPEN-ITEMS.md`, plus the comments inside `src/*.cs` that describe the lines beneath them.
**Date**: 2026-10-25.
**Build audited**: **1092**. `build/build-number.txt` = `1092`; `bin/Release/ARS.dll` and the live `Scripts\AutosportRacingSystem\ARS.dll` are one file, sha256 `8e3ab22dc3b3ff8a1dda4dfd3cd8a7f5c8017f36206032ffa3210dea6c983285`. Source `HEAD e851a09`, `src/` clean.
**Method**: read-only — no edit, build, deploy, commit or game run. Three instruments: (a) a citation resolver over 22 docs, pulling all **287** `file.cs:line` references and printing each against the line it now points at; (b) a constant differ that pulls every backticked identifier declared in `src/` with a numeric initialiser and flags the doc windows whose numbers do not contain the live value — **87 candidates**, each read by hand on both sides; (c) a comment differ over `src/`, plus `git blame` on every constant that moved. **VERIFIED** = read in the code, or recomputed arithmetic, or the instrument's own count. **PROBABLE** = one step rests on engine or drive behaviour not observed here.

**Verdict**: the doc set describes a **faster, earlier car than the one shipped** — a lane mover at 14 m/s²/12 m/s that has run at 26/24 since `5635848`, a countersteer band ending at 1.5× the peak that ends at 2.5×, a damper "not capped" that is capped, and a nitrous pair the code no longer has. Five of the thirteen rows would send the next session at the wrong knob or rebuild what exists. The **release draft repeats one of them to the player** (nitrous 1:2.5 against a code pair of 1 and 5). Two source comments still describe the generation before them (B4, B5), and both sit above the constant they mis-state. What holds is the part that is hardest to fake — the per-frame pipeline order, the player/AI split, the settings-key mechanism and the inert-ceiling claim all check out.

## Not verifiable from the repository

1. **Whether the shipped nitrous pair is balanced (B5).** 5 against 1 is arithmetic; whether a rival at 5 and a player riding GTA's native force (1 + 3.0 × powerMod) feel equal is a track measurement, and the comment's "1:2.5" is the record of one that was made against a pair the code has since changed. One drive with `AiNitroPct` at 100 and a bottle each settles it; nothing in the tree does.
2. **Whether `SteerCeilingFactor` 0.90 is deliberate** (R1). The value is in the store and the field; no commit message in the last forty states the intent, and the doc's 1.00 is consistent with a *law* written when the value was 1.00. Whether the default was lowered to sit just under the peak, or left at 0.90 by a tuning pass, cannot be told from the files.
3. **Which of `AGENTS/AGENTS-WIP.md`'s present-tense values were true when written and which were wrong then** (R3). The file is a session log without per-line build markers; the honest reading is "stale by an unknown number of builds", not "wrong at the time".
