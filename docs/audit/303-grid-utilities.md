## Structural note

Both grid bugs are one missing invariant. `BuildGridSlots` is documented as "built to order" (`TrackLoader.cs:1175-1176`)
but **neither builder guarantees ≥ wanted + 2 slots**, while `Place` assumes `positions.Count >= racers.Count` (the
comment at `AutosportRacingSystem.cs:2586-2587` shows the author knew `Place` reads two slots *past* each car — that
read is guarded at `GridBuilder.cs:32-34`; the base index is not). One guard — refuse to place, with G3's message fixed —
closes G1, G2 and G3 together.
