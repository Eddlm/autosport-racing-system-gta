# AUDIT 02 — race cycle: start, finish, abandon, restart, cleanup

**Surface**: the race state machine in `src/AutosportRacingSystem.cs` (`RaceState`, `InstanceTrack` / `InstanceGrid` / `StartRace` / `SetupRace` / `StartCountdown` / `CleanRacers` / `CleanEverything`), the finish and grace-timer block in `OnTick`, the per-racer teardown (`Racer.Delete`, `Racer.Initialize`, DNF parking), and every menu row that enters or leaves a race.
**Date**: 2026-10-25.
**Build audited**: **958**. `build/build-number.txt` = `958`; `bin/Release/ARS.dll` and the live `Scripts\AutosportRacingSystem\ARS.dll` are one file, sha256 `12fb8b8ff31667a6…`. Source `HEAD 9bdb9af`, **31** commits ahead of `origin/master` (`749157c`). The session in `Log.log` (13:26–13:29 today) was a **spectator** race — 14 AI cars, no player racer (`Log.log:315` "Adding player to grid" is followed by an `Initialize` block with no player car), so the deployed build has not exercised the player-on-grid start in that log.
**Method**: read-only. No build, deploy, commit or game run. Every row cites source lines; the one row that leans on the live log cites its line numbers. **VERIFIED** = the mechanism was read and every writer of the value was enumerated here; **PROBABLE** = one step rests on engine or SHVDN behaviour that was not observed.
**Verdict**: the loop has no single owner. Three teardown paths (`CleanEverything`, `CleanRacers`, `OnAbort`) each clear a different subset of the same statics, and the per-race deadline survives every path that re-instances a race — the only reset that does not also end the race is the Restart row's own line. **Two blockers**, both one-line fixes, both on the Race menu a player meets on day one: the mod deletes the player's own car whenever they are not sitting in it, and a new race inherits the previous race's grace timer and kills itself on it.

## The loop as the code actually runs it

Every entry point, what it clears, and what it leaves. This is the shape the findings sit on.

| Entry (menu row) | Code path | Clears | Leaves behind |
|---|---|---|---|
| **Start Race** (`:841`) | `StartRace` → `InstanceTrack` (→`CleanRacers`, `LoadTrack`) → `InstanceGrid` (`LoadGrid`, `PlaceCars`) → `AddPlayerToGrid` → `SetupRace(true,true)` | racers + blips, track props, `LeaderboardFinish`, grid/track flags, `MissionFlag` | `_raceTimedFinishMs` (**B2**), `HelpMessages` (**F1**), the player's car if they are out of it (**B1**), and silent spectating when the player is on foot (`:2495-2505`; the only notify is the empty-roster one, `:2454-2459`) |
| **Restart Race** (`:849`) | `SetupRace(true,true)` only (falls back to `StartRaceFromMenu` when `PlayerParticipating` is false) | racer lap state (`Initialize`), `LeaderboardFinish`, the timer (`:855`) | `ParkedDNFs`, `HelpMessages` (**F1**); throws on an empty roster (**F2**) |
| **Load Track** (`:743`) | `InstanceTrack` → `CleanRacers` + `LoadTrack` | racers, track props | race silently ended (**R4**), timer still armed (**B2**) |
| **Build Grid** (`:827`) | `InstanceGrid` → `CleanRacers` + `LoadGrid` + `PlaceCars` | racers, reborn grid | as Load Track; `RaceStatus` stays `None` so the world join chevron can fire (`:2046`) |
| **End Race** (`:870`) | `CleanEverything` | racers, props, flare effects, no-collision pairs, leaderboard, DNF counter, timer, route nodes, flags | `TrackPoints`/`Corners`/`IsPointToPoint` (**F8**); the player's car if out of it (**B1**) |
| **Race completes** (`:2228`) | stragglers classified → reward → `Finished`→`CleanEverything` | as End Race | as End Race; `Finished` never observable (**F3**) |
| **Script reload** (`Aborted`) | `OnAbort` | camera, screen effects, freecam, props, racers, scaleforms | `Game.MissionFlag` (**F7**); the player's car if out of it (**B1**) |
| **Player leaves / dies** | *nothing* | — | racer frozen at the car, no DNF, race waits on the grace timer (**R2**) |

Two structural notes that the table makes obvious and that no single row can carry:

- **The finish test is downstream of the per-racer core tick in the same `OnTick`** (`:2158-2177` then `:2188-2236`), so any exception thrown by a racer skips the finish and cleanup for that frame. The live session shows the mechanism 38 times in three minutes — `Log.log:587` and its siblings, `System.ArithmeticException … at System.Math.Sign … at ARS.Racer.ComputeSteering` — each one dropping the rest of the batch, the finish check and the cleanup, because `_nextInLine` is not advanced past the thrower (`:2170-2171`). The defect is the steering NaN (AUDIT 01's "Observed, out of this surface"); the race-cycle consequence is that a persistent one freezes the field and the finish with it.
- **The player is only a racer when they own a vehicle at that instant** (`:2495-2505`). Everything else in the loop treats "a race" as "the AI field", which is why abandonment, death and the all-DNF case have no owner (R1, R2).
- **There is no join path.** `Start Race` is a full re-instance — track reload plus a fresh grid — so a player mid-race who presses it restarts everything, and if they are on foot at that instant the new race runs as a spectator race with no message. The one row that could add a car to a running field is `Build Grid`, and it clears the field instead (`:1473`).

## Owed by the owner

**Decisions (no wheel time)**

1. **B1's fix direction.** The smallest honest fix is to branch on `Driver.IsPlayer` instead of `IsInVehicle`, i.e. "the player's car is never deleted by a teardown, whatever seat they are in". The alternative — keep the car only while it is the player's last vehicle — is a different promise; pick one.
2. **R1: restore an all-parked guard or retire the requirement.** The guard has to be keyed on *a race running* and *no non-DNF racer left*, not on `Racers.Count == 0` (that was `715f76f`'s false positive). Either way `TEST-PLAN.md:111` and the code must say the same thing.
3. **R2: is abandonment a DNF?** A player out of their car for N seconds could be DNF'd (and the race released), or the grace timer stays the only answer. This is a behaviour call, not a defect.
4. **R4: keep the staged rows at all.** They are dev-facing and off by default; gating them on `!RaceIsRunning` is one line, retiring them is none.

**Drives (one batch, one race)**

1. B1 and B2 together: start a race, step out of the car, End Race (B1); then a second run that reaches the first finisher and Start Race from the menu (B2). Both are menu sequences, not laps — the batch is minutes.

**Blockers**

1. **B1** — the player's car is deleted by every teardown when they are not in it.
2. **B2** — a new race inherits and dies on the previous race's grace timer.
