# AUDIT 305 — the nine fixes of builds 1093–1105, against their own promises

**Surface**: the nine code fixes committed between `e851a09` (build 1092, audit 200's base) and `6a1fcbc` (HEAD) — **B1** `8107174` · **B2** `b998b53` · **B3** `ed6065e` · **B4** `4042447` · **B6** `89b5461` · **B7** `41ea441` · **B8** `8d1087d` · **B9** `53805ae` · **B10** `835ae49` + `13a07a9`. B5 is parked (`47109f0`) and is not covered. Each fix is judged twice: does it close the failure it claims, in today's source, at the line that proves it — and did it change what already existed, for the worse. B9 and B3 (the two that touch existing data) and B10's teardown edges are read with extra suspicion.

**Date**: 2026-10-26.

**Build audited**: source `HEAD 6a1fcbc`, `src/` clean; deployed **1105** — `build-number.txt` reads 1105 in both the tree and the live `Scripts\AutosportRacingSystem\`, whose `ARS.dll` is byte-identical to `bin/Release/ARS.dll`, sha256 `0e3b2d13ec0f7b09eedc347f3cb16369174e1b7c709e7745baae2a6a8a261a65` (mtime 00:59). The card says 1103: stale by two builds; the binary this report judges is 1105. The live `Log.log` (mtime 23:50) predates the fix session and was read as found — **no post-fix log exists**, so every runtime closure below is a code read.

**Method**: read-only — no edit, build, deploy, commit or game run; the only file written is this one. Instruments: `git show` of the ten fix commits, the source at `6a1fcbc`, the live `Log.log` and `Settings\Menu-Settings.ini`, `docs/audit/200-…`, `209`, `304`. **VERIFIED** = read in the code today, or arithmetic on it; **PROBABLE** = deduced, one step rests on engine or SHVDN behaviour; **NOT VERIFIABLE** = the artefact that would settle it is not on this machine. Nothing here is driver-verified.

**Verdict**: **nine of nine close the failure they claim in the code**; **four carry a named residual** (B6, B7, B9, B10), one of which — B10's resume-prevention — is conditional on nothing above it in the try throwing (§2, the release-note). None is a blocker. The fixes are one-liners and read cleanly; what they leave behind is edge-shaped: a zero-node file still throws, a burn that expires inside the last core tick is not cleared, the settings rewrite drops what the prune preserves, and the abort's state clears run last, behind everything that can throw.
