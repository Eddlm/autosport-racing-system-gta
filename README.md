# Autosport Racing System - ARS - [On Youtube](https://youtu.be/KnVMv-6BsrI?si=oBTz_U95TrUl5qWK)
A singleplayer racing script for GTAV. Race against AI oponents on any car, anywhere.

### Features - now

| Race anything  | Built to try and manage any kind of car or handling mod you throw at it.  |
|---|---|
| Race anywhere | Besides preset routes, you can create any racetrack you want. [HowTo](https://youtu.be/K-WGhfiu7r0?si=e1npNcKv3pT71kjr)  |
| Nitrous for everyone | EVERYONE gets the funny bottle. If you want. Toggleable. |
| Scratch made racing AI | Native AI is off. Rivals run on code specifically cooked up for racing. |
| Actual Intelligence | Trying to create AI able to challenge and beat real people is the whole point. I pulled no punches. |
| Customizable | Make it as fair or unfair as you need. See settings below. |
| Up to date | Plan is to update monthly from now on. Weekly for minor fixes. DON'T LAUGH.|
### Features - planned (if GTA VI does not make ARS forgotten by the people)
| Career mode  | Some kind of progression system, right now its all Quick Race kinda deal.  |
|---|---|
| Driver Personalities | Lost in the 0.9 rework, they will come back in 0.11. Names tied to styles, consistent session to session. |
| Racing Teams | Set up your team and race against other actual teams who have to buy cars and hire drivers, just like you. |
| Gamemodes | Banger races, Folk races, Team v Team, Touge, Impromptu Races (like my OG) |
| Street Races | Proper ambience for street racing. Race against loners, gangs... and the police. |

## Installation 

- Open _AutosportRacingSystem-DD-MM-YYY.zip_.
- Inside there is only a folder named _AutosportRacingSystem_. Drop it onto ``\\Grand Theft Auto V\Scripts\``-
- Full route becomes ``\\Grand Theft Auto V\Scripts\AutosportRacingSystem``\\(ARS.dll and other content)
